# Door ERP 使用手册

版本日期：2026-09-14  
适用版本：`feat/semicircle-handles-and-quote-form-improvements`  
使用方式：统一操作手册，不按岗位拆分；各环节负责人在同一条业务链中协作。

## 1. 系统用途

Door ERP 用于管理门类产品从图纸录入、绘制、审核、报价到订单、BOM、采购、库存、生产、质检和入库的全过程。

推荐主流程：

`图纸信息录入 → 图纸绘制 → 图纸初审 → 图纸终审 → 效果渲染/报价 → 订单确认 → BOM与下料 → 采购/库存/生产 → 质检 → 成品入库`

同一客户有多樘相似门时，可以复制已有图纸任务后修改差异项。几樘尺寸和参数完全相同的门，可以在订单数量中体现；参数不同的门应保留为独立明细。

## 2. 导航说明

### 图纸业务

- **任务总览**：查看绘图任务、各状态数量、今日新增和异常情况。
- **图纸绘制**：查看待绘制、待修改任务，复制或删除任务，并进入信息录入和绘制。
- **图纸初审**：检查图纸内容和参数，退回时填写修改原因。
- **图纸终审**：确认生产所需图纸已经完整，终审通过后才能进入正式订单链。
- **效果渲染**：按门扇、门框、门套/门头门柱、玻璃和五金分类管理参考素材，并生成普通效果图或可编辑的精准效果图。
- **报价系统**：关联图纸、计算报价、保存历史报价并导出报价单。

### 经营管理

经营管理当前处于内部试用和优化阶段，仅账号 `A` 可见。菜单可以在左侧导航中折叠，当前包括：

1. **订单确认**
2. **BOM与下料**
3. **生产管理**
4. **采购管理**
5. **库存管理**
6. **基础资料**

常用页面可以固定到导航上方。进入经营管理子页面时，菜单会自动展开。

## 3. 图纸业务操作

### 3.1 新建图纸任务

1. 进入“图纸绘制”。
2. 点击“图纸信息录入”。
3. 上传参考图片并填写订单、结构、尺寸、材质、颜色和五金信息。
4. 红色星号字段必须填写；颜色、门扇厚度、开向和拉手等必填项不可留空。
5. 保存后返回图纸绘制列表。

左右开与内外开分别选择，可以根据实际门型选择一个或多个方向。正反面门板或拉手相同时，按页面提供的“同正面”方式复用，避免重复录入。

### 3.2 复制相似任务

在图纸绘制列表中点击复制按钮。系统创建一条新的相同表单，随后只修改客户、项目、尺寸或款式等差异内容。复制任务不会覆盖原任务。

### 3.3 生成与预览图纸

1. 打开任务，检查必填项和尺寸。
2. 点击生成或预览。
3. 核对正反面、开向、门板、门框、包套、五金和尺寸标注。
4. 确认无误后下载 DXF。

若生成失败，弹窗会显示具体字段或模板原因。先按提示修正数据，再点击重试；不要连续重复提交。

### 3.4 初审与终审

- 初审重点检查结构、尺寸、款式、开向和标注。
- 终审重点检查可生产性、五金位置、包套外围尺寸和正反面一致性。
- 退回修改时填写明确原因，避免只写“有问题”。
- 终审通过后再用于订单确认，防止生产参数继续变化。

## 4. 效果渲染

效果渲染提供“快速 AI 生成”和“精准分区生成”两种方式。参考图需要先归入门扇、门套/门头门柱、门框、玻璃或五金，系统只把素材作用到对应部件，图纸结构、尺寸比例和五金位置始终优先。

操作时优先关联已经终审的图纸，也可以上传 DXF、完整订单图或单张线稿。普通图片选择精准模式时，系统会先推测部件区域，必须人工确认后才生成。精准结果可以只重新生成某个部件；需要后期编辑时，再在结果区点击“生成分层 PSD”，未点击不会创建 PSD 文件。快速 AI 结果如需 PSD，会先转入精准分区流程。

## 5. 报价系统

### 5.1 新建报价

1. 选择关联图纸项目，系统自动带入客户、项目、门型和尺寸。
2. 选择报价模式并填写单价、数量和附加项目。
3. 有气窗时，报价高度采用包含气窗在内的整体高度。
4. 有包套时，外围面积按图纸的含包套外围尺寸计算。
5. 检查每行数量、单价、金额以及页面底部总价。
6. 保存前在居中弹窗中再次确认宽、高尺寸。

### 5.2 修改历史报价

从最近报价中打开已有记录后，保存应更新当前报价；需要保留两个版本时使用“另存为新报价”。导出 JPG 和 Excel 前均应先预览，确认文字、金额和开票资料排版。

## 6. 订单确认

订单确认是销售数据进入生产链的正式入口。

1. 点击“新建订单”。
2. 选择已终审图纸及其对应报价单，系统自动带入客户、项目、产品、尺寸、数量、价格和交期。
3. 自动带入的数据仍可在确认前调整。
4. 不关联历史单据时，也可以手工录入订单。
5. 检查订单行数量、交期、单价和备注。
6. 确认订单后，系统按数量生成独立门樘生产编号和技术快照。
7. 客户实际付款后，在订单详情点击“登记收款”；收款计划只是约定，不代表已经到账。
8. 同一客户一次付款涉及多张 `TM` 订单时，填写实收金额后使用“自动分配”，也可逐单调整分配金额。
9. 错误收款不能删除或覆盖，应从实际收款记录执行冲销；冲销会恢复所有关联订单的未收金额并保留历史。

订单确认后若图纸关键参数发生变化，不应直接静默覆盖原数据，应取消后重新确认，或建立生产变更记录。

## 7. BOM与下料

该页面按订单归集门樘，每樘门保持独立生产编号、BOM版本和核验记录。

### 7.1 阶段一：BOM准备

1. 从左侧选择订单和门樘。
2. 点击“生成 BOM”。
3. 系统根据产品、门型和基础资料中的 BOM 规则模板生成草稿。
4. 补齐物料档案、规格、理论量、损耗率、计划量、单位和取得方式。
5. 取得方式可选择库存领料、采购、内部加工或外协加工。

“重新生成”会重新应用规则，手工调整前应先确认是否需要保留现有草稿内容。

### 7.2 阶段二：核验发布

1. 勾选资料完整的行。
2. 点击“核验选中”。
3. 处理所有阻断提示和缺少资料项。
4. 保存草稿。
5. 全部通过后点击“发布 BOM”。

发布后当前版本冻结，并自动产生物料需求以及采购、仓储和车间工作包。需要修改已发布 BOM 时，应填写原因并新建版本，不覆盖历史版本。

### 7.3 阶段三：下料执行

BOM 发布后的实际执行进度在生产管理中跟踪。无依赖关系的工作包可以并行处理；系统只阻止存在真实前置依赖或物料未齐套的项目。

当前门框加工工具仍可独立使用，但外皮端部异形、完整上下框规则和门框下料深化尚未完成，不应作为最终自动加工依据。

## 8. 生产管理

生产管理用于查看订单、门樘、物料齐套和工作包执行状态。

- 订单下达后，每樘门独立跟踪。
- 工作包按照实际依赖关系执行，无依赖项目可以批量或并行完成。
- 物料不足时先查看采购和库存状态，不手工填写虚假的进度百分比。
- 发生返工、暂停或异常时记录原因，保留事件轨迹。
- 全部生产环节完成后进入成品质检和成品入库。
- 发货读取 `TM` 订单的实际收款；尾款未收齐时默认禁止出库。特殊欠款发货必须填写授权原因和授权人，授权不会减少账面欠款。

## 9. 采购管理

采购管理统一处理全厂采购，不为每张订单重复建立供应商或仓库。

1. 在采购需求池查看 BOM 发布后产生的缺料需求。
2. 合并同供应商、同物料、相近交期的需求，建立采购订单。
3. 跟踪待下单、已下单、部分到货和已完成状态。
4. 分批到货时按实际数量登记，剩余数量继续保留为在途。

## 10. 库存管理

仓库是全厂公共物料存放位置，不隶属于某一张订单。

- **库存台账**：查看各仓库、库位和物料现存量。
- **待入库**：处理采购到货、生产完工等入库业务。
- **待领料**：按已发布 BOM 和工作包进行领料。
- **库存流水**：追溯入库、出库、调整和占用记录。
- **仓库与库位**：维护原料、配件、半成品、外协和成品仓。

不要通过直接修改库存数字代替入库或出库；库存变化应形成流水。

## 11. 基础资料

基础资料是订单、BOM、采购和库存共用的数据底座。

- 商品信息：维护内部物料编码、名称、规格、单位和类别。
- 供应商及产品：维护供应商、供应物料、价格和交期关系。
- BOM规则模板：按产品、门型和附加参数配置每樘或每扇用量、损耗、取得方式、工序和优先级。
- 仓库与库位：维护全厂仓储结构。

修改规则只影响之后新生成的 BOM 草稿，不应改变已经发布的历史版本。

## 12. 常见问题

### 页面切换较慢

先等待当前生成、上传或保存操作结束，再切换页面。若页面长时间没有响应，刷新后重新进入；已经成功保存的数据会从后端恢复。

### 预览或 DXF 无法生成

阅读弹窗中的具体原因，重点检查必填项、数字格式、模板块名称和尺寸范围。若仍失败，记录订单号、任务编号和弹窗原文。

### 找不到关联图纸或报价

检查图纸是否已经终审、报价是否确实关联该图纸、客户是否一致，以及搜索条件或日期筛选是否仍然生效。

### BOM无法发布

检查是否存在未匹配物料、计划数量小于等于零、未核验行或阻断级警告。全部处理后再发布。

### 操作后出现重复数据

不要连续点击确认、发布或保存按钮。系统对订单确认和 BOM 发布已做幂等保护；若界面没有及时刷新，先刷新列表再判断。

## 13. 数据备份与腾讯云更新

在腾讯云服务器的 `~/door-erp` 目录执行：

```bash
cd ~/door-erp && mkdir -p ~/door-erp-backups && BACKUP=~/door-erp-backups/data-$(date +%Y%m%d-%H%M%S).tar.gz && sudo tar -czf "$BACKUP" data && sudo chown "$USER:$USER" "$BACKUP" && git fetch origin && git switch feat/semicircle-handles-and-quote-form-improvements && git pull --ff-only origin feat/semicircle-handles-and-quote-form-improvements && sudo docker compose up -d --build backend frontend && sudo docker compose ps
```

更新前必须先完成数据备份。若任一步出现错误，后续通过 `&&` 连接的命令不会继续执行，应保留完整终端输出后再处理。

## 14. 当前暂缓功能

- 3D 下料预览。
- 外皮端部异形及完整上下框加工规则。
- 门框具体下料规则深化。
- 当前零件 DXF 和全部单件 DXF ZIP。
- BOM 版本逐行可视化差异。
- 更细的岗位权限配置。
- 下料工作台内的门框加工页签和门框结果可视化。

## 15. 每日操作检查

1. 新任务是否填写必填项并正确保存。
2. 图纸是否完成初审和终审。
3. 报价尺寸、数量、单价和总价是否正确。
4. 正式订单是否关联正确的终审图纸和报价。
5. BOM是否补齐、核验并发布正确版本。
6. 缺料是否形成采购需求，到货是否真实入库。
7. 工作包是否按依赖关系推进，异常是否记录原因。
8. 成品是否完成质检和入库。
