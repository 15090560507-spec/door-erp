# CAD 批注与可编辑图框验证

日期：2026-10-20

## 实现范围

- 生产批注按模板原始字高乘图框统一比例排版；字宽高比、原字体及内容不变，保留显式换行并自动折行。
- 图框保持原宽高比，门体、五金和尺寸标注不缩放、不移位。
- 下载 DXF 的副本将 ORDER_FORM / ORDERFORM 及其内部嵌套块展开到模型空间，属性转为实际 TEXT/MTEXT。隐藏属性和 ATTDEF 占位内容不转为可见文字。
- 复制图框显示属性时处理图层 0、BYBLOCK 颜色/线型/线宽/透明度和父级可见性。
- 内部缓存 DXF 不变；SVG、JPG 和内部业务仍读取保留图框引用的原件。下载副本有独立、带版本的缓存。

## 实际图纸与视觉核对

- 使用普通对开门、平移门、带气窗门、拱形门四组实际 CAD 生成参数，均加入中文车间批注。
- 在重新读取的下载文件上完成 DXF audit；逐一比较全部图框外模型空间实体的 DXF 标签，未改变几何、五金或标注结构。
- `tools/verify_cad_sheet_download.py` 将内部原件和下载副本按相同原图框窗口绘制为 1782 x 1260 JPG；四例可见像素差异比例均为 0（阈值为单通道灰度差大于 12）。平均像素差为 0 至 0.000022。
- 已人工查看普通门、平移门及拱形门样图，批注位于门体上方、表头下方，没有遮挡门体或标注。
- 单次冷拆框转换耗时为 **0.344 / 0.372 / 0.420 / 0.418 秒**，不包含 CAD 本体生成与 JPG 绘制耗时；重复下载复用转换缓存。
- 验证 DXF 样本用原始字节写入，避免 Windows 文本换行转换破坏 DXF 的二进制数据组。

样本目录：`F:/codex/cad-editable-sheet-verification`。

- `adaptive-0.dxf` 至 `adaptive-3.dxf`：保留图框块的内部原件。
- `editable-0.dxf` 至 `editable-3.dxf`：自动拆框的下载样本。
- `before-*.jpg` / `after-*.jpg`：图框自适应前后样图。
- `download-*.jpg`：下载副本在相同窗口的绘制结果。
- `download-verification.json`：转换时间、字节数及像素差异。

## 边界

- 超出原字体比例下可用区域的批注会触发布局告警并保留未被部分修改的图纸，不截断文字或改缩放门体来容纳内容。
- 不支持的图框参照明确返回错误；不静默下载缺失实体的拆框结果。
- 尚未在桌面 AutoCAD 中人工打开样本；验证基于 DXF 重读、结构审计、实体比对和绘图对照。
- 不修改业务数据、账号文件、既有 DXF 或云端部署。应用更新后需要重新生成并下载图纸，已有下载文件不会自动改变。
