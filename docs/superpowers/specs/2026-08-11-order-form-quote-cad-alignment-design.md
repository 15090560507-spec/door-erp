# 订货单、CAD 与报价对齐设计

## 目标

以最新 `template.dxf` 为准，将订货单抬头、产品名称和材料录入接入现有 Door ERP；同时修正一门一景标注、弧形气窗、遮挡容错、报价历史与 Excel 导出格式。现有门类 CAD 计算和报价价格规则保持兼容。

## 订货单字段

- 新增 `order_title`，写入模板属性 `TT`。默认值为“浙江西州将军铜门订货单”；下拉可选“杭州兰庭新贵门业”，并允许自由输入。
- 新增 `product_name`，为必填；默认“不锈钢镀铜门”。可选值为不锈钢镀铜门、纯铜门、全铝门、系统门、庭院门、铝艺栅栏、牌匾。
- `material` 是自由文本输入，例如 `0.8mm`。模板属性 `CPMC` 的内容为：材料非空时 `材料的产品名称`，否则仅产品名称。
- 保留旧 `zzcl` 数据读取兼容；新保存数据使用 `material` 和 `product_name`。`CPMC` 优先写入，新旧模板仍存在 `ZZCL` 时同步写入同一显示内容。

## 特殊产品模式

- 庭院门仍使用门类绘图；默认左、右、上、下门缝均为 `0`，上门槛为 `0`，下槛为吊脚且高度 `30mm`。用户可在表单中继续调整。
- 牌匾与铝艺栅栏不要求门类结构字段。录入表单只显示产品名称、材料、颜色、数量、客户/项目等订货信息；模板中其余门类属性写 `/`。不绘制门框、门板、门套、锁和五金几何。

## CAD

- 一门一景绘制时，左景与右景均生成独立宽度标注，使用各自输入的宽度。
- 弧形气窗的可见顶部使用 DXF `ARC`，不使用由直线组成的折线作为弧形外观。用于选择/填充的封闭边界可以保持带 bulge 的闭合多段线。
- 遮挡为可选视觉功能。任何单个 wipeout 的不合法边界、写入失败或排序失败都只记录并跳过；CAD 文件和 SVG 预览必须继续生成。
- 图纸绘制的两个操作统一显示为“预览 DXF”和“生成 DXF”。

## 报价

- 最近报价采用任务列表式界面：搜索、日期筛选、加载、选择和批量删除。
- 面积拆分模式中，当正面与反面门套都存在时，生成“正面门套面积”和“反面门套面积”两条明细，分别计算。
- 每份正式报价和 Excel 至少保留五条明细行；多于五条时自动扩展。
- Excel 明细列中：品名型号左对齐、底端对齐；其余列水平居中、底端对齐。现有金额、合计和大写金额公式保持可编辑。
- 修复报价输入区偶发空白，确保门组切换、关联项目回填和明细行 key 不会丢失表单状态。

## 生产管理

生产管理继续采用独立 ERPNext。Door ERP 的登录会话不会被错误地当作 ERPNext 登录；本次不实现单点登录，也不修改 ERPNext 的请求、认证或部署协议。

## 验收

- 最新模板可写入 `TT` 与 `CPMC`。
- 庭院门、牌匾、铝艺栅栏各能保存并生成预览；后两者无需门类字段。
- 一门一景显示左右两项尺寸标注。
- 弧形气窗生成 `ARC` 实体。
- 启用遮挡的 CAD 和 SVG 预览均可生成。
- 正反门套均可出现在拆分报价中。
- 两条报价明细导出后总共显示五行，且对齐方式符合要求。
- 后端 CAD/报价测试和前端构建通过。
