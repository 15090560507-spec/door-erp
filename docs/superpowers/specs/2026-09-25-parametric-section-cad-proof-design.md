# 参数化生产剖面 CAD 概念验证设计

## 1. 目标

生成一套可打开的 DXF 与 PNG 预览，用于验证系统对门套、门框、门扇的总装剖面、外皮、内骨架、折弯展开、方管下料和联动开孔的理解。

本图仅用于结构与数据组织讨论，图框内必须显著标注“概念验证，非生产依据”。不得进入正式下料、BOM 或生产发布流程。

## 2. 样例范围

采用一樘单门的合页边水平节点：

- 墙厚：200 mm。
- 成品高度：2100 mm。
- 门扇厚度：70 mm。
- 门套与门框：分体结构。
- 门套：外皮加折弯骨架。
- 门框：外皮加折弯骨架。
- 门扇：前后外皮加方管骨架。
- 设置一组合页联动开孔，用于演示门框和门扇对应构件的共同加工关系。

全部演示尺寸都必须列入图纸参数表，不隐含为厂内正式规则。

为保证第一版可重复生成，概念样例固定使用以下假设值：

| 项目 | 演示值 |
| --- | ---: |
| 门套外皮板厚 | 1.2 mm |
| 门套正面宽度 / 墙侧回边 | 80 / 25 mm |
| 门套折弯骨架板厚 | 1.5 mm |
| 门套骨架分段 | 40 / 30 / 20 mm |
| 门框外皮板厚 | 1.5 mm |
| 门框总深 / 正面宽度 / 止口 | 120 / 50 / 25 mm |
| 门框折弯骨架板厚 | 2.0 mm |
| 门框骨架 U 形分段 | 35 / 50 / 35 mm |
| 门扇正反外皮板厚 | 1.0 mm |
| 门扇合页边方管 | 40 x 30 x 1.5 mm |
| 门框与门扇装配间隙 | 4 mm |
| 合页孔型 | 30 x 100 mm 矩形演示孔 |
| 合页孔中心高度 | 250 / 1050 / 1850 mm |

这些值只用于验证图纸表达方式，后续必须由正式工艺卡替换。

## 3. 数据组织

每个构件统一拆成外皮和内骨架。内骨架类型限定为：

- 折弯骨架：输出成品截面、板材展开图和零件立面图。
- 方管骨架：输出成品截面、方管下料图和零件立面图，不生成虚假的板材展开图。

样例包含以下零件编号：

- `TRIM-SKIN-01`：门套外皮。
- `TRIM-SKELETON-01`：门套折弯骨架。
- `FRAME-SKIN-01`：门框外皮。
- `FRAME-SKELETON-01`：门框折弯骨架。
- `LEAF-SKIN-FRONT-01`：门扇正面外皮。
- `LEAF-SKIN-BACK-01`：门扇反面外皮。
- `LEAF-TUBE-01`：门扇合页边方管骨架。

## 4. 图纸布局

DXF 使用毫米单位，按四个区域排版：

1. 总装水平剖面图：墙体、门套、门框、门扇、装配间隙和连接关系。
2. 折弯成品截面图：各板件折弯后的轮廓、板厚、折弯角度和示意焊缝。
3. 展开与下料图：板件展开宽度、折弯线、折弯方向和顺序；方管显示规格、切割长度和孔位。
4. 零件立面图：零件宽度、高度、基准、孔位、数量和对应零件编号。

每个零件按“成品截面、展开或下料、立面”从左至右成组显示。总装图中的构件编号与零件区完全对应。

## 5. 加工特征

合页孔不作为无语义图元保存，而是作为联动加工特征：

- 特征编号：`HINGE-01`。
- 关联构件：门框外皮、门框折弯骨架、门扇前后外皮、门扇合页边方管骨架。
- 剖面视图：表达孔穿过的结构层。
- 立面视图：表达孔组的垂直位置、数量和间距。
- 定位基准：零件下端和合页边。
- 对齐约束：门框侧与门扇侧孔组同轴。

孔型、孔宽、孔高和三个孔中心高度采用第 2 节固定演示值，并在图纸参数表中标明尚未形成厂规。

## 6. 图层

至少使用以下语义图层：

- `REF-WALL`：墙体与参考结构。
- `SKIN`：外皮成品轮廓。
- `SKELETON`：折弯骨架和方管骨架。
- `CUT`：切割轮廓及孔槽。
- `BEND`：展开图折弯线。
- `WELD`：焊接位置。
- `CENTER`：中心线和对齐基准。
- `DIM`：尺寸标注。
- `TEXT`：标题、编号、参数和警示文字。

图层颜色用于屏幕识别，生产含义以图层名称为准。

## 7. 输出

- `parametric-section-proof.dxf`：可由 CAD 软件打开的概念验证图。
- `parametric-section-proof.png`：整张图纸的快速预览。
- 一份简短说明，列出所有演示假设、零件编号和需要用户纠正的工艺点。

## 8. 验收标准

- DXF 单位为毫米且可正常解析。
- 总装剖面能够区分门套、门框、门扇的外皮和内骨架。
- 每个板件都有成品截面、展开图和立面图。
- 方管骨架使用方管下料图，不伪装为板材展开图。
- 展开图包含总展开宽度、分段尺寸、折弯线、方向和顺序。
- 立面图包含零件宽高、孔位基准、孔组数量和间距。
- `HINGE-01` 在门框与门扇相关零件间保持联动关系。
- 图纸显著标明“概念验证，非生产依据”。

## 9. 非目标

- 不推导或宣称任何未经确认的厂内折弯补偿、折弯半径、K 因子、焊接标准或公差。
- 不把粗略参考 DXF 直接转换为生产图。
- 不接入订单、BOM、算料、库存或生产发布流程。
- 不在本轮建立完整的工艺模板管理界面。
