# Door ERP 工作区与任务总览视觉升级设计

## 目标

在已完成持久化左侧导航的基础上，统一 Door ERP 内部业务页面的视觉系统，并彻底重做“任务总览”，使页面在保持高信息密度和操作效率的同时，具有清晰、克制、现代的工业管理软件质感。

本次不改变 CAD、报价、订单、生产、采购、库存等业务字段、校验规则、接口和单据流转。

## 左侧导航调整

- 完全移除左上角“西州将军 / Door ERP”品牌名称与黄色方形标识。
- 品牌区原位置改成轻量的侧栏收放控制，不占用额外标题空间。
- 手机端仍保留必要的当前页面标题和菜单按钮，但不显示品牌标识。
- “经营管理”改为可折叠导航组。
- 经营管理默认收起；进入订单、生产、采购、库存或基础资料页面时自动展开。
- 用户手动展开或收起后保存本地状态；离开相关页面时沿用最后状态。
- 折叠动画只改变高度和透明度，不触发业务页面重排。

## 工作区设计系统

建立一套可复用的工作区语义样式，逐步覆盖现有页面：

- `workspace-page`：页面背景、最大宽度和响应式留白。
- `workspace-header`：标题、说明、状态和主要操作。
- `workspace-toolbar`：搜索、筛选、切换和批量操作。
- `workspace-panel`：独立业务区块，8px 圆角、细边框、轻阴影。
- `workspace-metrics`：指标面板网格和数字层级。
- `workspace-table`：表头、行悬停、选中、空状态和横向滚动。
- `workspace-control`：输入、选择、日期、文本域的统一焦点和禁用状态。
- `workspace-dialog`：居中弹窗、遮罩、标题、内容和操作区。
- `workspace-empty`：图标、标题和必要操作，不使用表情符号作为主要图标。

设计语言采用近黑文字、灰白与浅灰紫工作区、白色内容面板、荧光黄绿色重点状态，以及蓝、绿、橙、红等业务语义色。禁止装饰性渐变和无业务含义的大面积彩色背景。

## 任务总览重做

### 页面标题区

- 标题为“任务总览”，副标题说明当前绘图流转和风险状态。
- 右侧提供刷新时间和“图纸信息录入”主要按钮。
- 标题尺度适合工作台，不使用营销页超大字号。

### 核心指标

显示五项：全部图纸、今日新增、待绘制、待修改、已通过。

- 每项包含图标、名称、主数字和简短状态说明。
- 待修改使用风险色；已通过使用成功色；当前筛选使用荧光黄绿色边框或底色。
- 可筛选指标保持按钮语义，不可筛选指标不伪装成按钮。

### 图纸流转趋势

- 展示最近 14 天新增与终审通过数量。
- 使用清晰双系列柱状图或柱线组合，不引入额外图表依赖。
- 网格、坐标和标签保持轻量，零数据时显示完整但安静的空图表。
- 数据变化只做一次短促进入动画。

### 流程健康度

- 显示待绘制、待初审、待终审、待修改、已通过的数量和占比。
- 用统一进度轨道表达比例，点击可筛选任务列表。
- 突出待修改和积压状态，不使用仅靠颜色传达含义的设计。

### 客户与门型分布

- 客户图纸量使用排序横向条形排行。
- 门型分布使用比例条与数量，不绘制难以比较的装饰性环图。
- 点击客户或门型可继续沿用现有搜索筛选行为。

### 待办与列表衔接

- 总览下方保留管理设置、筛选工具栏和任务列表。
- 区块之间使用一致留白和面板层级，取消视觉上零散的白色卡片堆叠。
- 总览指标、排行和流程分布继续直接驱动下方筛选，不新增第二套状态。

## 业务页面覆盖

### 图纸工作区

- 统一任务列表、详情标题、沟通记录、CAD 操作、审图操作和弹窗。
- 保持图纸信息录入按钮、返回列表、保存修改等现有位置和业务逻辑。
- 用图标替换纯表情符号空状态和提示图标，但不更改提示内容。

### 报价与效果渲染

- 统一配置面板、素材库、预览、历史记录、报价表单和导出区的面板层级。
- 保留大尺寸表格与预览所需横向空间，不强制压缩字段。

### 经营管理

- 订单、生产、采购、库存、基础资料使用相同页面标题、指标、选项卡、面板和表格风格。
- 高频主操作使用蓝色；当前选项卡使用深色或荧光黄绿状态，避免整块高饱和蓝色。
- 异常、缺料、逾期和质检失败保持醒目但不扩大面积。

## 动画与性能

- 面板进入、导航折叠、选项卡和提示反馈使用 160 至 220ms 动画。
- 图表动画只使用 CSS 和 SVG，不增加运行时图表库。
- 不对大型表格逐行执行进入动画。
- 不使用持续循环的装饰动画。
- 遵循 `prefers-reduced-motion`。
- 所有样式变化不得重新引入页面切换延迟或阻塞导航。

## 验证标准

- 左上角不再显示名称或 Logo，展开与收窄侧栏均无空白错位。
- 经营管理默认收起，相关页面自动展开，手动状态可记忆。
- 任务总览在 1440px、1024px、390px 视口下无重叠、溢出或不可点击区域。
- 总览全部指标、状态、客户和门型筛选仍能驱动原任务列表。
- 图纸、报价、渲染、订单、生产、采购、库存和基础资料页面具有一致的标题、面板、工具栏、表格及表单视觉。
- 页面切换性能不低于上一版，效果渲染离页请求仍可正确取消。
- ESLint、TypeScript、生产构建及关键 Playwright 截图验证通过。
