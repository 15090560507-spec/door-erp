# 生产履约混合工作台扩展设计

日期：2026-08-05

## 1. 背景与问题

当前生产履约首版只显示已经正式下达的生产订单。图纸终审通过后，如果销售尚未点击“下达生产订单”，该任务既不在生产订单列表中，也没有清晰的待办入口，因此用户会误以为终审数据没有同步。

本次扩展不改变“销售点击下达生产订单是进入生产履约的唯一节点”这一规则。终审通过任务只作为待下达数据展示，点击下达后才创建生产订单、冻结图纸参数和 DXF 快照。

同时将现有基础页面扩展为混合生产工作台，补齐订单进度、异常提醒、生产单据以及 Excel 和打印/PDF 输出。

## 2. 目标与边界

### 2.1 目标

- 让终审通过但未下达的任务在生产订单页面明确可见。
- 将生产总览、订单列表、订单详情和生产单据组成一套高效工作台。
- 补齐 BOM、采购、库存、下料、排单、工序、质检、入库和发货的查看与操作能力。
- 为主要生产单据提供 Excel 和浏览器打印/PDF 输出。
- 保持现有 CAD、报价和效果渲染功能不受影响。

### 2.2 不在本次范围

- 不自动生成 BOM。
- 不修改 CAD 绘图算法或模板。
- 不修改报价计算逻辑和报价导出模板。
- 不修改效果渲染 Provider 或请求协议。
- 不实现复杂 MRP、库存预占、工时计件、成本核算或多级审批。
- 一张生产订单仍只对应一樘门。

## 3. 核心数据流

1. 图纸任务完成终审，状态变为“已通过”。
2. 生产工作台读取所有已通过任务，并排除已经按当前终审版本直接下达过的任务。
3. 待下达任务显示在生产订单列表顶部，状态统一显示“待下达”。
4. 所有拥有生产履约权限的用户可以查看待下达任务。
5. 只有拥有 `production.sales` 权限的用户可以填写交期和销售说明并执行下达。
6. 下达成功后创建正式生产订单，冻结任务参数、终审信息、参考图片和 DXF 文件。
7. 已下达任务立即从待下达区域移除，并进入正式生产订单列表的“BOM准备”阶段。

终审任务不提前写入 `production.db`，避免把订单前期状态和生产状态混在一起。

## 4. 混合生产工作台

### 4.1 生产总览

总览显示可点击指标：

- 待下达
- 今日下达
- 即将到期
- 已逾期
- 缺料
- 待下料
- 生产中
- 待质检
- 待入库
- 待发货
- 已完成

点击指标进入对应筛选结果。交期预警规则首版固定为：要求交期在未来三天内且订单未完成时为“即将到期”；要求交期早于当前日期且订单未完成时为“已逾期”。

### 4.2 生产订单列表

列表顶部为“待下达”区域，字段包括：

- 订货单位
- 项目名称
- 门型
- 门宽、门高
- 开向
- 终审时间
- 终审人
- 操作

正式生产订单区域支持按以下条件组合筛选：

- 生产单号、客户、项目关键字
- 阶段
- 状态
- 负责人
- 缺料状态
- 要求交期起止日期

列表显示交期预警、负责人、当前阶段和最新进度。点击订单后打开详情工作区。

### 4.3 订单详情

订单详情使用标签页，避免将所有表单一次性展开：

- 订单概况
- 进度时间轴
- BOM
- 采购与库存
- 综合下料单
- 排单与工序
- 成品质检
- 成品与发货

详情页保留复制、撤回、暂停、恢复和作废操作，并对高风险操作进行二次确认。

## 5. 订单概况与时间轴

订单概况展示冻结数据：来源任务、客户、项目、交期、门型、尺寸、开向、材质、正反面款式、销售说明、下达人和下达时间，并提供冻结 DXF 下载。

时间轴从生产事件和各业务记录聚合，至少显示：

- 下达、复制、撤回、暂停、恢复和作废
- BOM 草稿保存和发布
- 采购单创建、下单和到货
- 下料单生成、开始和完成
- 排单修改
- 各生产工序开始、完成或跳过
- 质检结果
- 成品入库
- 发货单创建、出库和完成

每条记录显示时间、操作人、动作和备注。

## 6. 生产单据

### 6.1 BOM

- 手工新增、编辑和删除材料。
- 草稿可编辑，发布后锁定。
- 发布后才允许生成综合下料单。
- 支持 Excel 和打印/PDF。

### 6.2 采购与库存

- 可从 BOM 外购物料选择生成采购单，也可手工建立采购单。
- 显示采购数量、已到货、未到货和到货进度。
- 支持采购入库、生产领料、生产退料、其他入库和报废流水。
- 禁止超量采购入库和重复成品出库。
- 采购单和库存流水支持 Excel 和打印/PDF。

### 6.3 综合下料单

- 从已发布 BOM 生成，一张生产订单只能有一张综合下料单。
- 记录理论数量、实际数量、单位、下料人、完成状态和备注。
- 支持 Excel 和打印/PDF。

### 6.4 排单与工序

- 排单字段：计划开始日期、计划完成日期、生产人、缺料状态、负责人。
- 固定工序：下料、激光/冲孔、折弯、焊接组装、表面处理、装配、包装。
- 工序支持待开始、进行中、已完成和不适用。
- 工序变化写入时间轴。

### 6.5 成品质检

- 记录合格或不合格、质检人、问题说明、退回工序、备注和图片凭证。
- 所有必要工序完成后才能判定合格。
- 质检单支持打印/PDF。

### 6.6 成品入库与发货

- 质检合格后必须先办理成品入库。
- 一张发货单可以包含多张已入库生产订单。
- 一樘门不能重复加入多个发货单，也不能拆分发货。
- 发货单记录客户、地址、联系人、电话、物流、运单号和备注。
- 发货单支持 Excel 和打印/PDF。

## 7. 导出设计

生产单据导出统一由后端生成，并要求登录和相应业务权限。

- Excel 使用 `openpyxl` 生成，保留数字格式、公式、自动换行、适配行高和打印区域。
- 打印/PDF 使用独立的认证打印页面和打印样式，浏览器打印时输出 A4。
- 不生成 JPG。
- 导出文件名包含单据类型、单号和日期。
- 不复用或修改现有报价 Excel、JPG、PDF 导出逻辑。

## 8. 接口设计

新增或增强以下接口：

- `GET /api/production/pending-release`
- `GET /api/production/dashboard`
- `GET /api/production/orders`，增加负责人、缺料和交期筛选
- `GET /api/production/orders/{id}/timeline`
- `GET /api/production/orders/{id}/approved-dxf`
- `GET /api/production/orders/{id}/documents/{type}.xlsx`
- `GET /api/production/orders/{id}/documents/{type}/print`
- `GET /api/production/purchases/{id}/export.xlsx`
- `GET /api/production/purchases/{id}/print`
- `GET /api/production/inventory/export.xlsx`
- `GET /api/production/shipments/{id}/export.xlsx`
- `GET /api/production/shipments/{id}/print`

现有下达、BOM、采购、库存、下料、排单、工序、质检、入库和发货接口继续复用，并在需要处补充状态校验和事件记录。

## 9. 权限

- 所有拥有任一生产履约权限的用户都可以查看待下达任务、生产总览和被授权的生产信息。
- 只有 `production.sales` 可以下达和复制生产订单；`production.sales` 或 `production.manager` 可以在下料前撤回生产订单。
- `production.technical` 管理 BOM 和技术资料。
- `production.purchase` 管理采购。
- `production.warehouse` 管理材料和成品库存。
- `production.schedule` 管理排单。
- `production.cutting` 管理综合下料单。
- `production.worker` 更新生产工序。
- `production.quality` 执行成品质检。
- `production.shipping` 管理发货。
- `production.manager` 管理暂停、恢复、作废和异常流程。

权限必须在后端校验，前端隐藏按钮仅用于改善操作体验。

## 10. 反馈与异常处理

- 加载、提交和导出都显示明确状态。
- 成功和失败使用可关闭反馈弹窗。
- 重复下达、缺少关键字段、状态不允许、库存不足、未质检、未入库等错误返回具体原因。
- 高风险操作需要二次确认。
- 页面接口失败时保留当前输入，不清空表单。

## 11. 测试与验收

- 终审通过未下达任务显示在列表顶部。
- 已下达任务不再出现在待下达区域。
- 普通生产用户只读，销售可以下达。
- 同一终审版本不能重复直接下达。
- 总览指标、组合筛选和交期预警正确。
- 时间轴包含关键业务动作。
- BOM 未发布不能生成下料单。
- 采购不能超量入库。
- 工序未完成不能判定成品质检合格。
- 未质检合格不能成品入库，未入库不能发货。
- 重复出库不会产生重复库存流水。
- 所有 Excel 和打印页面需要认证并可正常输出。
- CAD、报价、线稿、效果渲染和安全测试保持通过。

## 12. 实施顺序

1. 待下达查询、生产总览和筛选接口。
2. 混合工作台与待下达操作。
3. 订单详情和时间轴。
4. 生产单据页面增强。
5. Excel 与打印/PDF 输出。
6. 权限、反馈、状态边界和回归测试。
