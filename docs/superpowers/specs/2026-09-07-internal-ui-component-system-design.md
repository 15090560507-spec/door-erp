# Door ERP 内部页面组件化视觉升级设计

## 目标

在保留现有业务流程、字段和页面路由的前提下，升级图纸绘制、图纸信息录入、报价、订单确认、生产、采购、库存与基础资料的内部视觉层级，并统一弹窗与操作按钮。重点解决以下问题：

- 旧页面字号偏小、表单密度失衡，信息读取困难。
- 白色页面中散落纯黑按钮，操作层级不协调。
- 全局颜色覆盖造成黑底蓝字等低对比度组合。
- 弹窗结构和操作区不一致，部分内容过密或滚动体验不稳定。
- 页面虽共享侧栏，但内部面板、筛选栏、列表和表单仍缺少统一语言。

## 设计原则

1. 生产业务优先：界面应安静、清晰、适合长时间重复操作，不做营销式大标题或装饰性卡片堆叠。
2. 语义决定颜色：按钮颜色由操作等级决定，禁止根据旧 Tailwind 类名进行全局强制换色。
3. 每个操作区只保留一个主操作；其他命令使用浅色、描边或文字按钮。
4. 黄色绿色仅用于当前选中、关键状态和少量强调，不作为大面积页面底色。
5. 文本、控件和固定格式区块必须在桌面与移动端保持可读，不发生遮挡或横向页面溢出。

## 视觉系统

### 页面与面板

- 页面背景使用中性浅灰 `#F4F4F7`。
- 主面板使用白色，边框使用 `#E2E2E8`，圆角统一为 8px。
- 次级分组使用 `#F7F7F9`，通过背景与分隔线建立层级，不在卡片内部继续嵌套卡片。
- 阴影保持轻微，只用于浮层、主要工作面板和弹窗。

### 字体层级

- 页面标题：22-28px，按页面密度选择。
- 区块标题：15-17px。
- 正文和输入内容：不小于 14px。
- 标签、辅助信息和状态：不小于 12px；仅时间戳等极次要信息允许 11px。
- 正文颜色使用 `#26262B`，辅助文字使用 `#676770`，禁用文字使用 `#96969F`。

### 操作颜色

- 主操作：深灰 `#2B2B30` 背景与白色文字，不能使用纯黑。
- 次操作：白色或浅灰背景、灰色边框、深色文字。
- 选中状态：荧光黄绿 `#E8F56B`，深色文字。
- 链接与焦点：保留蓝色，但蓝色文字不能落在深色背景上。
- 危险操作：红色文字或浅红背景；只有最终确认删除时使用实心红色。
- 成功操作：绿色状态或浅绿背景，避免与主操作竞争。

## 组件边界

### Button

建立主操作、次操作、弱操作、危险操作、图标操作五类样式。按钮高度统一为 36px 或 40px，图标优先使用 Lucide。页面不得再依赖匹配 `bg-[#007AFF]` 字符串的全局换色规则。

### Modal

统一弹窗骨架：遮罩、标题栏、可滚动内容区、固定底部操作栏。默认最大宽度 560px，复杂选择弹窗可扩展至 880px；最大高度 85vh。关闭按钮固定在右上角，取消在左或右侧弱化位置，确认按钮置于操作栏末端。弹窗圆角为 8px，不使用超大圆角。

### FormSection

图纸信息表单按业务语义组成区块：区块标题、必要说明、字段网格和可折叠高级项。桌面保持两至三列自适应字段布局；移动端单列。字段标签、必填标识、输入框高度、错误提示和只读状态统一。

### Toolbar

筛选、搜索、日期和状态选择集中在同一工具栏。主要新增操作放在页面或面板标题区，不再独立漂浮在大面积白色背景中。

### ListRow

图纸任务列表按客户/项目、门型尺寸、流程状态、报价确认状态和时间建立固定信息层级。复制、删除等命令使用图标按钮并放在同一操作区，避免形成独立竖条。

## 页面改造范围

第一轮覆盖所有高频公共组件，并重点处理：

1. 图纸绘制列表和任务卡片。
2. 图纸信息录入与修改页面的全部表单区块。
3. 报价系统的输入面板、历史列表、预览区和相关弹窗。
4. 订单确认的列表、编辑区和候选图纸弹窗。
5. 生产、采购、库存、基础资料的标题、工具栏、选项卡、表格和操作按钮。
6. 当前代码中的通用弹窗，包括配件、AI 设置、报价历史、裁切编辑、生产下达和通知弹窗。

不调整业务字段、数据接口、权限规则、计算逻辑、CAD 生成逻辑或单据状态机。

## 实施顺序

1. 移除危险的全局按钮颜色强制覆盖，建立语义化 CSS 变量和基础类。
2. 建立 Button、Modal、FormSection、Toolbar 的共享视觉规范。
3. 迁移图纸绘制与图纸信息录入，解决当前截图中的密度和可读性问题。
4. 迁移报价与订单确认弹窗和主要操作区。
5. 让生产、采购、库存和基础资料复用相同规范。
6. 清理仍存在的低对比度组合、过小字号和零散深色按钮。

## 兼容与风险控制

- 保留原有组件事件、表单状态与 API 调用，只替换结构外壳和样式类。
- 对高风险大组件采用局部迁移，避免一次重写 `DoorForm` 或报价页面造成业务回归。
- 共享样式必须通过显式语义类生效，不使用包含字符串选择器批量覆盖 Tailwind 颜色。
- 弹窗迁移保持原有键盘、遮罩关闭和禁用状态逻辑。

## 验收标准

- 不再出现黑底蓝字、灰底浅灰字等低对比度组合。
- 页面正文与输入内容不小于 14px，常规标签不小于 12px。
- 每个操作区最多一个深色主按钮，且主按钮与关联内容处于同一区域。
- 图纸表单在 1440px 和 1920px 桌面宽度下可清晰读取，在 390px 移动端不发生页面横向溢出。
- 所有改造弹窗在常见视口内居中，标题和底部操作始终可访问。
- 页面切换、表单录入、保存、复制、删除、预览和下载行为保持不变。
- 前端正式构建通过；对图纸绘制、信息录入、报价、订单确认和至少一个经营管理页面进行截图回归，控制台无新增错误。
