# A1022 拉手方向与气窗报价高度修正规格

日期：2026-09-13

## 目标

修正两项独立但高频的图纸与报价规则：

1. A1022 拉手块按图面左右位置选择，左侧使用 `Z1022`，右侧使用 `Y1022`。
2. 存在玻璃或封闭气窗时，报价高度包含气窗，即从下槛最下侧计算到气窗上框最上侧。

## A1022 块选择

- 不再因为正面或反面视图额外交换 `Y1022` 与 `Z1022`。
- 拉手目标位于图面左侧时使用 `Z1022`，位于图面右侧时使用 `Y1022`。
- 遮罩块与最终插入块必须使用同一映射，避免遮罩和实体方向不一致。
- 规则适用于单门、对开门、子母门、四开门及两定两开门现有拉手目标。
- 其他拉手类型保持现有规则不变。

## 含气窗报价高度

- 基础门高为 `dh`。
- 当 `sel_qc` 为“玻璃”或“封闭”，且 `qc_height > 0` 时：
  - 含气窗门框总高 = `dh + qc_height`。
  - 报价主产品高度使用该总高。
  - 门框面积、外围高度、外围面积、内外包套面积及包装规格同步使用该总高。
- 当气窗为“无”或气窗高度无效时，总高仍为 `dh`。
- 不改变表单中 `dh` 的语义，避免 CAD 端再次叠加气窗导致双倍计算。

## 实现边界

- A1022 修正在 CAD 绘制层完成。
- 报价高度修正在共享的 `calculateDoorAreas` 中完成，报价页和表单面积提示共用同一结果。
- 不修改 DXF 模板块内容，不改变其他门型、拉手和包套宽度规则。

## 验证

1. 生成含 A1022 的正反面 DXF，验证左侧块为 `Z1022`、右侧块为 `Y1022`。
2. 使用 `dh=2200`、`qc_height=400` 的玻璃气窗样例，报价高度应为 `2600`。
3. 同一样例选择无气窗，报价高度应恢复为 `2200`。
4. 运行 CAD 针对性测试、前端 ESLint 和生产构建。
