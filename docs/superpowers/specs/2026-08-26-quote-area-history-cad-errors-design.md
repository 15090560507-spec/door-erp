# 报价外围面积、历史保存与 CAD 错误反馈设计

## 目标

本次只修正四条现有业务链路，不改变报价字段和 CAD 绘图规则：

1. 报价模式“外围面积 x 单价”与图纸的含包套外围尺寸保持一致。
2. 网页报价预览中的开票资料按固定逐行结构排版，不再依赖空格对齐。
3. 历史报价载入后可以覆盖保存，并保留显式“另存为新报价”能力。
4. CAD 预览或下载失败时，用户能看到具体失败原因，后端保留可排查日志。

## 外围面积计算

继续复用 `frontend/src/lib/doorAreas.ts` 作为图纸表单和报价系统的唯一面积计算入口。

普通外包套：

- 外围宽 = 门框宽 + max(0, 左包套宽 - 左压框) + max(0, 右包套宽 - 右压框)
- 外围高 = 门框高 + max(0, 上包套宽 - 上压框)

例如门框宽 1000mm、左右包套宽 100mm、左右压框 20mm，外围宽为 `1000 + 80 + 80 = 1160mm`。

内包套使用同样原则，采用内包套左右/上压框。外门头门柱、一门一景和外门头门柱 2 使用各自左右宽度、上部高度和对应压框。若正面外装饰存在，报价模式的外围规格采用正面外围；只有内包套时才采用反面外围；都不存在时采用门框规格。

门套面积仍按“外围矩形面积减门框面积”计算，正面和反面分别计算并单独列入报价。

## 历史报价保存语义

前端把“当前报价身份”和“当前内容是否已保存”分开管理：

- `currentQuoteId`：当前正在编辑的报价编号；新建时为空，载入历史后为历史编号。
- `isDirty`：表单内容是否在最近一次保存后发生变化。

操作规则：

- 新建报价点击“保存”：调用 `POST /api/quotes`，创建编号并进入编辑状态。
- 载入历史报价点击“保存”：调用 `PUT /api/quotes/{id}`，覆盖该报价，不新增记录。
- 点击“另存为新报价”：始终调用 `POST /api/quotes`，生成新编号，并把新编号设为当前报价。
- 清空表单：退出历史编辑状态。
- 修改客户、日期、说明、门组、项目或明细：保留当前报价编号，但标记为未保存。
- 未保存时导出：提示先保存，避免导出旧版本；保存成功后才能导出当前编号。

后端更新接口沿用创建接口的验证和数据规范化逻辑，保留 `id`、`createdAt`，写入 `updatedAt`。创建记录也写入 `updatedAt`，其初始值等于 `createdAt`。

页面在操作区显示“新建报价”或“正在编辑报价 #ID”，并提供“另存为新报价”按钮，避免用户误以为每次保存都会新增。

## CAD 预览与下载错误反馈

后端为 `/api/generate_cad` 和 `/api/generate_cad_preview` 使用统一异常转换：

- 已知 `HTTPException` 保留原状态码和原因。
- 参数或业务校验错误返回 400，并说明无效字段。
- 模板缺失、块缺失、DXF 生成或 SVG 渲染异常返回 500，响应提供经过整理的具体原因，同时服务端使用 `logger.exception` 记录堆栈。
- 不在响应和日志中输出令牌或其他敏感信息。

前端 `generateCad` 在 Blob 响应失败时读取 Blob 中的 JSON 或文本，提取 `detail/message/error`，不再丢失后端原因。预览和下载按钮共用可关闭的错误弹窗；弹窗标题区分“CAD 预览失败”和“DXF 生成失败”。加载状态必须在 `finally` 中复位，保证失败后可再次尝试。

这次不修改 CAD 算法本身。若具体表单仍失败，弹窗和日志需要明确指出失败阶段和原因，作为后续修复对应组合的依据。

## 接口变化

- 新增 `PUT /api/quotes/{quote_id}`：更新现有报价。
- 现有 `POST /api/quotes`、导出接口和数据结构保持兼容。
- CAD 接口路径和成功响应不变，只统一失败响应。

## 测试

1. 面积单元测试：普通外包套 `1000 + (100-20) * 2 = 1160`；左右不同宽度/压框；仅内包套；无包套。
2. 报价数据库/API 测试：更新不增加记录、保留创建时间、生成更新时间；另存新增记录。
3. 前端逻辑测试：载入后保存走更新；修改后不能直接导出；另存生成新编号。
4. 预览测试：开票资料逐行显示，不包含用于对齐的大段空格。
5. CAD 错误测试：JSON 错误和 Blob 错误都能提取具体原因；预览、下载失败后加载状态正常结束。

## 不在本次范围

- 不改变 CAD 几何绘制算法、块放置和业务字段。
- 不重做报价模板整体视觉。
- 不引入报价版本树、审批流或数据库迁移。
