# 报价关联搜索、拉手与包套面积规则设计

## 目标

修复报价系统只能在首次加载任务中搜索图纸的问题；补充两个正面拉手选项和客备指纹锁 CAD 映射；统一图纸录入页与报价页的内外包套面积和外围规格规则。

## 任务搜索

- 报价页首次只加载最近任务，保持页面打开速度。
- 用户在“关联图纸项目”输入关键词时，使用现有 `GET /api/tasks?q=...` 在服务端搜索全部任务。
- 搜索字段沿用现有后端规则，覆盖客户、项目、订单号、任务编号等字段。
- 对输入做短暂防抖，忽略过期响应；搜索失败时保留当前列表，不影响已选任务。
- 下拉最多展示 20 条匹配结果，选择后仍通过任务 ID 读取完整任务并生成报价。

## 拉手与指纹锁

- 正面、反面共用的拉手选项源增加“凹槽拉手”和“凹槽拉手+灯带”；本次只保存名称并写入订货信息，不绘制 CAD 块或轮廓。
- “客备指纹锁”与“安志杰AF-12”“Q3指纹锁”“T5指纹锁”共用 `AZJ` 块、安装位置、门扇选择和镜像方向。
- 前端默认选项、后端默认选项及持久化下拉配置保持一致。

## 面积与外围规格

统一计算以下数据：

- 门框面积：门框宽乘门框高。
- 外包套面积：正面带外包套后的矩形面积减门框面积，仅在存在外包套或正面外装饰结构时显示和参与报价。
- 内包套面积：反面带内包套后的矩形面积减门框面积，仅在存在内包套时显示和参与报价。
- 外围规格：存在正面外包套/门头门柱/一门一景时，使用正面外围宽高；没有正面外装饰但存在内包套时，使用反面外围宽高；两者都没有时使用门框宽高。
- 内外包套同时存在时，分别显示“外包套面积”和“内包套面积”，外围规格固定采用正面外围尺寸，不把内包套宽度叠加到正面尺寸。
- 报价模式“门框面积 + 门套面积”分别生成外包套、内包套报价行；外围面积模式使用上述外围规格。

## 验证

- 创建超过 100 条任务后，较早任务仍能通过关键词搜索并关联。
- 验证无包套、仅外包套、仅内包套、内外同时存在四种面积组合。
- 验证客备指纹锁生成 `AZJ`，位置和方向与安志杰 AF-12 一致。
- 验证两个新拉手出现在下拉配置中且不会触发额外 CAD 几何。
- 前端构建、Python 语法检查和相关专项测试通过。
