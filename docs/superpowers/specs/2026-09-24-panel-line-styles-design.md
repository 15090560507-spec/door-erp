# 门板线型与对角框样式设计

## 背景

现有门板设置存在三个问题：

1. `图案内部线距` 并非所有 B2/B4 图案都会实际使用；六格、八格采用固定均分，双边框和四角回纹又存在最小距离限制，因此用户修改数值后常看不出变化。
2. B2/B4 控件名称带有“玻璃线条”，但该区域实际是在配置门板分区内的图案，名称过窄。
3. 整块门板缺少四边对角框和三边对角框两种常用结构。

本次只调整门板线型和门板样式，不改变门型尺寸、门框、门套、五金及报价逻辑。

## 目标

- B2/B4 图案参数所见即所得。
- 增加等距竖条图案。
- 增加四边对角线条门板样式。
- 增加与用户手绘图一致的三边对角线条门板样式。
- 正面、反面、子门正面和子门反面均支持新样式，并保持现有继承规则。
- 旧订单和旧图纸不需要迁移即可继续生成。

## 界面设计

### B2/B4 图案

- `正面门板B2玻璃线条` 改为 `正面门板B2`。
- `正面门板B4玻璃线条` 改为 `正面门板B4`。
- 反面和子门使用相同命名规则。
- 图案选项新增 `竖条`。
- `图案内部线距(mm)` 解释为相邻 CAD 线中心之间的实际距离；CAD 线没有实体宽度，因此无需另算净空。
- `竖条` 从图案区域水平中心向左右展开，保持两侧余量尽量对称；输入值直接决定相邻竖线距离。
- 现有需要内部间距的图案直接使用输入值，不再用固定 `50mm` 下限覆盖用户输入。
- 六格、八格仍按格数均分，其格数定义与距离输入互斥；选择这两种图案时，界面说明其内部线距不参与均分计算。

### 四边对角线条

- 门板样式新增 `四边对角线条`。
- 显示 `外边距(mm)`，默认 `30`。
- 在门板外轮廓内按统一外边距生成闭合内矩形。
- 外轮廓四角分别连接内矩形四角，形成四个对角拼接角。
- 显示 `内部填充`，复用现有门板填充样式。
- 填充范围为闭合内矩形，不覆盖对角框。

### 三边对角线条

- 门板样式新增 `三边对角线条`。
- 显示 `锁边偏移(mm)`，默认 `150`。
- 显示 `上下及合页边宽度(mm)`，默认 `60`。
- 锁边内线与锁边平行，从门板上边贯通至门板下边。
- 上边内线、合页边内线和下边内线组成三边框。
- 只在合页侧绘制上、下两个斜接角；确认图为左合页时表现为左上、左下，镜像门扇则随合页侧镜像；锁边侧不绘制对角线。
- 上下内线终止于锁边内线，内部形成可填充区域。
- 单门及每个门扇按实际开向确定锁边与合页边，不能固定为屏幕左右。
- 显示 `内部填充`，复用现有门板填充样式。

## 数据模型

为避免与 H 型、两列式等已有偏移字段混用，每个门板面新增独立参数：

- `panel_border_inset`：四边对角线条外边距，默认 `30`。
- `panel_three_side_lock_offset`：三边对角线条锁边偏移，默认 `150`。
- `panel_three_side_inset`：三边对角线条上下及合页边宽度，默认 `60`。

反面、子门正面和子门反面分别使用现有前缀规则：

- `back_panel_*`
- `child_panel_*`
- `child_back_panel_*`

内部填充复用每组已有的 `fill_a`。不新增另一套填充枚举。

所有新增字段在前端默认数据、TypeScript 类型、Pydantic 请求模型、绘图参数映射和任务持久化数据中保持一致。旧数据缺少字段时使用默认值。

## 绘图规则

### 参数校验

- 所有距离必须大于 `0mm`。
- 四边外边距必须小于门板净宽和净高的一半。
- 三边宽度必须小于门板净高的一半。
- 三边宽度与锁边偏移之和必须小于门板净宽。
- 参数无效时返回明确的中文校验错误，不允许静默跳过绘制。

### 坐标方向

- 先通过现有 `panel_lock_edge` 取得当前门扇锁边。
- 由锁边推导合页边和绘图方向。
- 正反面、左右开、对开门和子母门均沿用同一方向函数，避免镜像错误。

### 图层与填充

- 结构线继续写入 `A-DOOR-PANEL`。
- 填充继续使用现有 hatch 模板库。
- 填充先限定在内轮廓，再绘制结构线，避免填充覆盖边线。

## 兼容规则

- 现有样式名称和参数保持不变。
- `back_panel_same_as_front=true` 时，新参数随正面一起继承。
- `child_back_same_as_front=true` 时，新参数随子门正面继承。
- 固定款式仍按原规则覆盖布局，不自动切换到新对角线样式。
- 旧任务未包含新增字段时，由请求模型和前端默认值补齐。

## 测试

### 后端几何测试

- `竖条` 按输入线距生成，并以区域中心对称展开。
- 修改内部线距后，生成线坐标随之变化。
- 四边对角线条生成闭合内矩形和四条角线。
- 三边对角线条生成锁边贯通线、三边内线及仅两个合页侧角线。
- 左开、右开和背面视图中的锁边方向正确镜像。
- 内部填充落在内轮廓中。
- 非法参数返回可读错误。

### 参数链测试

- 新字段从 API 请求完整传到绘图参数。
- 保存和重新打开任务后数值不丢失。
- 正反面和子门继承行为符合现有开关。

### 前端验证

- B2/B4 标签不再出现“玻璃线条”。
- 选择不同门板样式时只显示相关参数。
- 新输入项默认值正确，已有订单可以正常打开。
- TypeScript 构建通过，无布局溢出。

## 验收标准

1. 用户修改竖条内部线距后，新 DXF 中相邻竖线距离与输入一致。
2. 四边样式的外边距可控，默认 `30mm`，内部可填充。
3. 三边样式与确认图一致：锁边贯通，三边成框，仅合页侧两个斜接角；默认 `150mm/60mm`。
4. 新样式在正面、反面及子门上均可使用。
5. 现有门板样式和旧任务生成结果不回归。
