# 图纸录入、绘制工作流与任务总览改造设计

## 目标

在不重建任务系统的前提下，提升相似订单录入效率，明确录入与绘制入口，增加可用于日常调度的图纸任务总览，并把门框下料工作台严格限制给销售小A。

## 范围

本次包含六类改动：表单默认值与校验、开向复选、任务复制、绘制入口与状态关系、任务总览、下料权限。生产管理中的综合下料单不属于门框下料工作台，不受权限调整影响。

## 一、表单字段规则

### 颜色

- 新表单默认值为空。
- 颜色保持可选择、可自行输入。
- 新建任务和修改保存时必须填写颜色。
- 历史任务中的空颜色允许打开和查看；保存时按新规则校验。

### 门扇厚度

- 新表单默认值为空。
- 使用可输入下拉框，预设 `80`、`100`，允许输入其他正数。
- 新建任务和修改保存时必须填写。
- 前端使用空字符串表示未填写；后端使用可空数值接收，进入 CAD 计算前必须通过必填及正数校验。

### 开向

- “左右开”和“内外开”显示为两个视觉分组，均使用复选框。
- 左右开组支持：左开、右开、左右开。
- 内外开组支持：内开、外开、内外开。
- 凡显示“结构与开向”的门类，两组都必须至少选择一项。
- 牌匾、铝艺栅栏、雨棚、其他等简单产品不显示该区域，也不校验开向。
- 保存值继续使用字符串，避免大规模迁移旧数据：
  - 左右开组保存 `""`、`"左开"`、`"右开"` 或 `"左右开"`。
  - 内外开组保存 `""`、`"内开"`、`"外开"` 或 `"内外开"`。
- CAD 订货单勾选按包含关系输出：`左右开` 同时勾选左右，`内外开` 同时勾选内外。
- 需要单一正反面基准的既有几何计算中，双选时使用左开和内开作为稳定主视图基准；勾选信息仍完整保留。

## 二、图纸绘制任务复制

### 入口

- 图纸绘制列表中，每条任务在“删除”按钮左侧增加“复制”按钮。
- 复制操作使用明确的后端接口，不由前端拼装不完整数据。

### 复制内容

复制以下内容：

- 全部录入表单参数。
- 客户沟通文字。
- 参考图片。
- 客户、项目、门型和尺寸等由复制后的参数重新生成摘要。

不复制以下内容：

- 已生成 CAD 或预览图。
- 审核意见、修改历史。
- 报价状态、订单确认状态。
- 生产订单及生产关联。

副本使用新任务 ID、当前创建时间，状态固定为“待绘制”。复制成功后刷新列表并提示新任务已创建。

任务新增不可变字段 `created_at`，使用上海时区 ISO 时间记录真实创建时间。现有 `date` 字段继续表示表单交期，不能再用于“今日新增”统计。历史任务缺少 `created_at` 时仍计入总量和状态分布，但不猜测创建日期，也不进入按日趋势。

## 三、绘制入口与状态关系

- 顶部导航不再直接显示“图纸信息录入”。
- “图纸绘制”页面顶部增加主操作按钮“图纸绘制”。
- 点击后进入现有图纸信息录入表单，使用空白默认值创建新任务。
- 提交成功后返回图纸绘制列表，新任务进入“待绘制”。
- “待绘制”统计状态等于待绘制的任务。
- “待修改”统计审核退回的任务。
- “今日新增”按不可变的 `created_at` 统计当天新建及复制的任务，不把交期或普通编辑计为新增。
- 现有审核状态流保持不变：待绘制 → 待初审 → 待终审/待修改 → 已通过。

## 四、导航与任务总览

### 导航

- 顶部第一项改为“任务总览”，进入系统后默认展示。
- 删除导航末尾重复的“任务总览”。
- “图纸信息录入”继续作为内部模块存在，供“图纸绘制”按钮进入，不作为导航按钮。

### 总览内容

任务总览使用现有任务数据，不新建统计数据库。页面包括：

1. 核心指标：图纸总数、今日新增、待绘制、待修改、已通过。
2. 近 14 天趋势：每天新增图纸数量及通过数量；没有创建时间的历史任务不进入趋势。
3. 状态分布：待绘制、待初审、待终审、待修改、已通过。
4. 客户排行：按任务数量展示主要客户。
5. 门型分布：单门、对开门、子母门、两定两开、四开门及其他产品。
6. 下方任务列表：保留搜索、日期和状态筛选。

点击状态、客户或门型统计后，将条件应用到下方任务列表。统计卡使用紧凑工作台布局，以白、灰为主，蓝、绿、橙、红表达业务状态；使用表格化数字、细网格和轻量图形体现技术感，不采用装饰性大屏或深色单一配色。

图表使用项目内原生 React、CSS 和轻量 SVG 绘制，不增加大型图表依赖。

## 五、下料权限

门框下料工作台以稳定账号 UID `A` 识别销售小A：

- 非 `A` 用户的顶部导航不显示“下料”。
- 非 `A` 用户直接访问 `/door-cad/frame` 时跳回任务总览并显示无权访问提示。
- `/api/door-cad/frame/*` 全部接口增加 UID `A` 后端校验，非法访问返回 HTTP 403。
- 不能只依赖显示名称“销售小A”，避免用户改名后权限失效。
- 生产管理中的综合下料单接口和页面保持现状。

## 六、错误处理

- 缺少颜色、门扇厚度或任一开向组时，前端在提交前指出具体字段，后端返回一致的中文错误。
- 复制源任务不存在时返回 404；复制失败不产生半成品任务。
- 非销售小A访问下料接口统一返回“仅销售小A可访问下料工作台”。
- 历史空字段任务允许只读打开，但发生保存动作时执行新校验。

## 七、测试与验收

### 后端

- 新建和修改任务的颜色、门扇厚度、两组开向校验。
- 左右开、内外开双选的 CAD 勾选结果。
- 复制任务字段、清空字段、状态、ID 和创建时间。
- 下料 API 对 UID `A` 返回成功，对其他用户返回 403。

### 前端

- 默认值为空及可输入下拉框行为。
- 两组复选至少选择一项。
- 复制按钮位置和复制后刷新。
- 导航入口、绘制按钮及提交后的模块跳转。
- 总览统计、筛选联动和空数据状态。
- 非销售小A看不到下料入口且不能直接进入页面。
- 执行前端构建，并检查桌面与移动端无横向溢出和文字重叠。

## 非目标

- 不调整生产管理的综合下料流程。
- 不引入新的角色权限配置后台。
- 不修改现有审核状态名称。
- 不建设独立数据仓库或实时 BI 服务。
