# B2 and Transom Reference Patterns

Approved workflow: add reference recognition beside each B2 selector and rectangular glass transom selector. Upload/drop/paste, crop, compare original with vector preview, adjust true band width/inset/fixed detail zones, then apply only to the current drawing or additionally save a personal template. Template saving is optional and never implicit. Both choices keep an immutable geometry snapshot in the drawing form; reopening never invokes AI automatically. Existing back-same-as-front switches remain authoritative.

Reuse quotation AI Base URL, endpoint, API Key and normalized model, but not its extraction prompt, parser or mutable prompt setting. Server-only credentials. First version accepts orthogonal straight-line/rectangle/return-pattern graphs, not arbitrary floral curves or arched transom clipping. AI supplies validated normalized centerline paths and stretch zones, never executable code or raw SVG. Deterministic geometry generates constant-width, unioned closed contours; fixed edge detail zones retain millimetre sizes while the middle stretches. Invalid or too-small targets fail visibly rather than distorting or silently dropping geometry.

Recognition is an explicit paid action. Durable bounded-concurrency jobs survive navigation; unfinished jobs after server restart become retryable errors. Idempotency keys prevent retries from duplicating a submitted recognition. Results require explicit visual review before applying. The model can miss lines; warnings and source comparison remain visible. No claim of production-ready automatic recognition or guaranteed latency.

Drawing entry roles may create recognition jobs and personal templates; drawing task roles may read a known job referenced by a shared drawing. Personal template lists are owner-scoped. No unauthenticated access, arbitrary URL fetch from user inputs, secrets in job storage/logs, or unrestricted generated code. Images are validated and resized/compressed before durable storage/API submission. No real paid model calls during automated verification.

Persistence keys: reference_patterns snapshots for panel_b2, back_panel_b2, child_panel_b2, child_back_panel_b2 and transom; reference_pattern_jobs stores pending job IDs. Inactive snapshots are retained when choosing a built-in style but only selected reference styles are drawn. No changes to quotation semantics or existing CAD templates.
