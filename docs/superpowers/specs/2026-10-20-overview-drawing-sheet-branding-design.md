# 总览直达绘制与订货单品牌规则

日期：2026-10-20。用户确认方案并选择“留白，继续修改”。

## 已确认规则

- 点击任务总览中的项目卡片，切换至图纸绘制并载入同一任务；不新建或复制任务，不因切换重置该任务 ID。跳转本身不修改业务状态，保存继续走现有流程。
- 卡片内删除、复制、报价状态等独立操作继续独立响应，不触发进入绘制。保留当前导航提醒和后台权限检查。
- 订货单抬头新增“众鼎门业”，保留“浙江西州将军铜门订货单”“杭州兰庭新贵门业”及自定义输入。按输入值显示，不擅自追加“订货单”。
- 所有抬头在原标题格内水平、垂直居中；长标题等比缩字号，不拉伸、不越框。
- 仅默认西州抬头保留原 Logo 和“西州将军门业”。众鼎、兰庭新贵及其他非默认抬头均删除左上角品牌文字和图案。
- 左上角隐藏品牌后留白，不合并标题格、不删表格线、不改变原图框宽高比。
- 门体、五金、尺寸标注、批注与其他单元格不变。普通门、简单产品、SVG 预览、打印 JPG 和自动拆框下载使用一致规则。
- 模板缓存保持原样，每次生成只修改私有 DXF 文档，避免自定义抬头影响后续默认抬头。

## 边界和验证

- 不增加新页面或权限，不自动修改历史图纸文件；更新后重新生成生效。
- 模块切换后的打开动作使用待打开任务 ID，不能直接同时设置模块和任务而被既有清理 effect 清空。
- 品牌区依据真实表格分区识别，仅删除完全位于区域内部的图案和品牌文字；边界线保留。无法识别需要处理的模板时明确报错，不猜坐标删图。
- 验证默认、众鼎、兰庭、自定义长标题和空白回退，标题锚点、字体边界、原网格与门体数据、生成顺序隔离及拆框前后效果。
- 用浏览器验证总览卡片点击、键盘进入、任务 ID/参数载入、模块切换、返回列表、独立按钮和未保存提醒；使用 mock API 或独立 DATA_DIR，不改云端业务数据。
