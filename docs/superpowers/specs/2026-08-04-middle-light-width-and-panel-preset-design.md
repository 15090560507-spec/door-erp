# 中门见光宽与固定款式反面默认值修正

## 目标

1. 四开门、两定两开存在左右立柱时，中门内空宽和见光宽均以两根立柱的内侧边为尺寸端点，不再使用中间门板边缘。
2. 五个固定门板款式统一使用同一套反面默认布局：A 区为锁边侧 180mm 空白，B 区为 100mm 竖条填充，C 区为剩余宽度且不填充。

## 适用范围

- 固定款式：紫荆花款、钱币款、竖条款、流星雨款、四方纳福款。
- 有立柱的四开门和两定两开使用立柱内侧标注。
- 无立柱时保留现有中间门区域标注逻辑。
- 固定款式为空时保留用户自定义的正面、反面和子门门板参数。

## 实现设计

### 标注

绘制四开门和两定两开时已经计算左右立柱的实际绘制边界。中门内空宽在存在立柱时使用 `left_pillar_inner` 到 `right_pillar_inner`；不存在立柱时继续使用当前中门范围。见光宽复用同一组立柱内侧坐标，并继续遵循内开标正面、外开标反面的现有规则。

### 门板固定款式

前端应用固定款式时写入：

- `back_door_panel_style = 三列式布局`
- `back_panel_three_col_a = 180`
- `back_panel_three_col_b = 100`
- `back_panel_three_col_c = 0`，由绘图端计算剩余宽度
- `back_panel_fill_a = 空`
- `back_panel_fill_b = 竖条`
- `back_panel_fill_c = 空`

后端固定款式兜底逻辑使用完全相同的参数，使旧任务重新生成 DXF 时也获得一致结果。

## 验证

- 验证有立柱四开门和两定两开的中门内空宽端点等于两根立柱内侧。
- 验证无立柱时原标注范围不变。
- 验证五个固定款式的反面均为 A=180、B=100、C=剩余，且只有 B 区使用竖条填充。
- 验证清空固定款式后，自定义门板设置不被覆盖。
