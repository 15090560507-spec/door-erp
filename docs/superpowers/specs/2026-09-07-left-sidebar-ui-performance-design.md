# Door ERP 左侧导航与页面体验改造设计

## 目标

将现有每页重复渲染的顶部导航改为全局持久化左侧导航，统一各业务页面的视觉语言与交互反馈，并重点消除从“效果渲染”等重页面切换时的明显停顿。

本次只调整应用壳层、导航体验、全局基础样式和与路由切换直接相关的性能问题，不改动 CAD、报价、订单、生产、采购和库存的业务规则。

## 视觉方向

- 桌面端采用近黑色左侧导航和柔和灰白工作区，借鉴参考图的克制、高对比布局。
- 当前导航使用荧光黄绿色作为状态提示；业务主按钮继续使用蓝色，成功、警告和错误保持各自语义色。
- 页面背景、面板、表格和表单建立统一的颜色、边框、阴影、间距与圆角变量。
- 面板和业务卡片圆角不超过 8px，避免过度卡片化；页面区段保持无框或完整工作面板布局。
- 动画时长控制在 160 至 220ms，使用统一缓动曲线。仅对导航展开、菜单出现、按钮反馈和页面进入做轻量动画。
- 支持 `prefers-reduced-motion`，系统要求减少动态效果时关闭非必要动画。

## 全局页面壳层

新增持久化 `AppShell`，由根布局统一包裹已登录业务页面：

- 登录页不显示业务壳层。
- 桌面端左侧栏默认展开，显示图标和模块名称，可折叠为仅图标窄栏。
- 折叠状态保存在浏览器本地，下次访问沿用。
- 手机和平板窄屏使用顶部移动栏加抽屉式侧栏；打开抽屉时锁定背景交互，支持点击遮罩和按 Escape 关闭。
- 右侧内容区根据侧栏宽度自动调整，不要求各业务页面自行设置边距。
- 页面切换时侧栏不卸载，只替换右侧路由内容，从而保持交互连续性并减少重复初始化。

现有各页面和局部 layout 中重复的 `TopNav` 将移除，避免嵌套导航和重复鉴权壳层。

## 导航信息架构

导航分为两个稳定业务组：

### 图纸业务

- 任务总览
- 图纸绘制
- 图纸初审
- 图纸终审
- 下料
- 效果渲染
- 报价系统

### 经营管理

- 订单确认
- 生产管理
- 采购管理
- 库存管理
- 基础资料

规则如下：

- “下料”仅账号 `A`（销售小A）可见，继续沿用现有权限规则。
- 常用页面可固定到导航顶部，沿用现有本地存储键，避免用户已固定的设置丢失。
- 当前页面由 URL 判定，不在点击导航时提前同步修改全局模块状态。
- 导航项使用 Next.js `Link` 进行生产环境预取；悬停和聚焦时也可主动预取重页面。
- 退出登录、当前用户和侧栏折叠控制放在侧栏底部。
- 仅图标模式为所有项目提供中文 tooltip 和无障碍名称。

## 页面基础样式

全局样式建立以下基础能力：

- 统一页面最大宽度、内容留白和移动端边距。
- 统一按钮、输入框、选择框、表格、提示条、空状态和加载状态的焦点与禁用样式。
- 保留现有 Tailwind 类兼容性，不进行全量业务组件重写。
- 通过少量语义类改善已有页面，不使用大范围选择器强行覆盖业务表格的尺寸。
- 页面进入动画只作用于右侧内容容器，不对大型画布、预览图和表格逐项动画。

## 路由性能修复

### 导航触发链

现有导航点击先调用 `setModule`，随后才调用 `router.push`。在重页面中这可能触发一次无意义的当前页重渲染。改造后：

- 路由由 `Link` 直接发起。
- 当前模块在 URL 变化后再同步，用于兼容仍依赖模块上下文的旧组件。
- AppShell 持久化，导航状态变化不再造成业务页重复装载。

### 效果渲染页

渲染页存在首屏多组接口请求及两个轮询定时器。改造要求：

- 所有轮询 effect 在离页时立即清除定时器并停止后续状态写入。
- 将独立首屏请求合并调度，避免同一时刻重复刷新配置、任务与素材。
- 对可取消请求使用 `AbortController` 或等价的失效标记，组件卸载后不再处理返回结果。
- 仅在任务处于运行状态时轮询任务详情；没有活跃任务时不创建定时器。
- 导航离开动作不等待渲染接口完成。

### 其他管理页

- 检查订单、生产、采购、库存和基础资料页面是否在每次渲染触发请求。
- 请求只放在稳定依赖的 effect 中，避免因函数引用变化重复加载。
- 大列表的派生筛选使用 memo，避免导航或提示状态变化导致重复计算。
- 不在本次引入复杂状态库或全量虚拟列表，保持改动范围可控。

## 错误与加载体验

- 路由切换保留当前页面直到新页面就绪，侧栏立即反馈选中状态。
- 页面级加载使用稳定尺寸骨架，避免布局跳动。
- 接口失败继续使用各业务页现有提示，不让全局页面壳层吞掉业务错误。
- 侧栏本地配置解析失败时回退默认展开和无固定项，不影响页面访问。

## 验证标准

- 登录后所有主路由只显示一套左侧导航，登录页无侧栏。
- 桌面展开、桌面折叠、窄屏抽屉三种状态均无内容遮挡和文字溢出。
- “下料”只对销售小A显示。
- 固定页面、侧栏折叠状态、退出登录均正常。
- 从效果渲染切换到任一模块时，导航立即响应，离页不被轮询或未完成请求阻塞。
- 订单、生产、采购、库存、基础资料和图纸页面切换后不出现重复导航或明显布局跳动。
- TypeScript、ESLint 和 Next.js 生产构建通过。
- 使用 Playwright 在桌面和移动视口检查关键页面截图、控制台错误和导航耗时。

## 不在本次范围

- 重做每个业务页面内部的完整信息架构。
- 改变业务权限模型、数据结构或后端接口。
- 引入 3D、插画、营销式首页或装饰性大动画。
- 为所有历史组件一次性替换全部 Tailwind 颜色值。
