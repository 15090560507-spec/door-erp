# CAD 线稿 JPG 与效果图比例设计

## 背景

图纸绘制页当前存在两类不同用途的图片：

- CAD 图纸预览包含正面、背面、尺寸标注和图框。
- 效果图生成只需要正面门体，但模型输出会映射到有限的标准宽高比。

如果这两类图片共用模糊的裁切边界，或在显示、上传、模型输出阶段使用不同画布比例，门框、门套和门扇就会被重新构图或拉伸，导致效果图与线稿比例不一致。

## 方案比较

### 方案一：继续使用浏览器 SVG 截图

实现简单，但只能按 SVG 当前 `viewBox` 导出，无法可靠识别 `ORDER_FORM` 图框，也无法保证效果图输入与门体真实外轮廓一致。不采用。

### 方案二：前端按颜色或可见像素裁切

可在浏览器内完成，但图层颜色、标注和复杂块会影响边界识别，结果不稳定。不采用。

### 方案三：后端直接解析 DXF 几何边界

分别识别 `ORDER_FORM` 图框和正面门体外轮廓，使用同一套几何坐标到像素坐标的等比变换。边界明确，可测试，也便于以后扩展 PDF 或批量导出。采用此方案。

## 图纸线稿 JPG

新增后端导出接口，输入与 DXF 生成接口相同的门参数，复用已经生成或缓存的 DXF。

导出规则：

1. 优先查找模型空间中名称为 `ORDER_FORM` 的块引用。
2. 计算块引用展开后的全部可见实体边界，以最外围图框作为裁切范围。
3. 如果模板没有可识别的 `ORDER_FORM` 块，则回退到整张模型空间可见实体边界，并返回回退标记。
4. 使用白色背景、等比缩放和固定边距输出 JPG，不改变 DXF 的横纵比例。
5. JPG 包含正面、背面、尺寸标注、文字和标题栏，文件名使用客户或任务名称。

图纸绘制页增加“下载线稿 JPG”按钮。按钮顺序为：

`预览 DXF`、`生成 DXF`、`下载线稿 JPG`、`生成效果图`、`保存修改`。

## 效果图比例

效果图仍只使用正面门体，不使用整张 `ORDER_FORM` 图纸。

处理规则：

1. 从 DXF 中识别正面视图，并排除背面、尺寸、文字、标注和 `ORDER_FORM`。
2. 使用门体结构图层的真实几何边界计算源宽高比；门框、门套和门扇共同决定边界。
3. 线稿图片使用该边界等比渲染，不做横向或纵向单独缩放。
4. 模型只支持有限标准画布时，选择最接近的画布比例，并在画布内居中补白或补背景；门体本身保持原比例。
5. 模型返回后，按提交前记录的门体目标区域进行等比校正和裁切，最终效果图的门体外轮廓宽高比必须与源线稿一致。
6. 页面使用 `object-contain` 显示结果，不通过 CSS 拉伸图片。

允许 AI 改变材质、光照和细节质感，但不得改变门体外轮廓、门扇分割、五金位置或门框门套比例。

## 数据与接口

- 线稿提取结果补充源几何宽度、高度、宽高比及门体在图片中的像素边界。
- 效果图任务保存上述结构元数据，便于生成后校验和历史记录恢复。
- JPG 导出接口直接返回 `image/jpeg`，并通过下载响应头提供文件名。
- 现有 DXF 和 SVG 预览接口保持兼容。

## 异常处理

- 未找到 `ORDER_FORM` 时允许回退导出，但前端提示“使用整图边界导出”。
- 未找到正面视图或门体结构边界时阻止效果图生成，并显示具体缺失内容。
- 生成结果无法完成比例校正时保留原结果供诊断，但标记为失败，不把错误比例图片显示为成功结果。

## 测试

- 使用含 `ORDER_FORM` 的样例 DXF 验证 JPG 裁切范围包含完整图框与标题栏。
- 使用不含 `ORDER_FORM` 的样例验证回退路径。
- 对单门、子母门、对开门和带气窗门验证正面门体宽高比。
- 验证线稿输入、模型画布内门体区域和最终效果图门体区域的宽高比误差不超过 1%。
- 验证前端按钮顺序及“保存修改”不再位于页面最底部。

## 不在本次范围

- 不改变 DXF 几何生成规则。
- 不修改门框、门套、门扇的业务尺寸计算。
- 不把尺寸标注或线稿叠加到最终效果图。
