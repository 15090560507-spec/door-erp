# CAD 打印与持久化绘图工作流实施计划

## 批次一：CAD 打印 JPG

1. 为后端加入 Matplotlib 运行依赖。
2. 先扩展 JPG 回归测试，覆盖固定 `5940 x 4200`、`ORDER_FORM`、黑白打印和属性文字。
3. 用 `ezdxf.addons.drawing` 替换 OpenCV/Pillow 手工图元绘制。
4. 保留 CAD 缓存接口并增加打印配置响应头。

## 批次二：效果图任务恢复

1. 扩展渲染任务查询接口，支持按 `sourceTaskId` 获取最新任务。
2. 图纸任务加载时恢复关联效果图任务。
3. 页面离开时停止本地轮询，但不清空或取消后端任务。
4. 返回页面后恢复生成中、已完成或失败状态。

## 批次三：未保存修改守卫

1. 保存任务加载/保存成功后的稳定快照。
2. 比较图纸参数、沟通内容和参考图，计算脏状态。
3. 为模块切换、返回列表和任务切换增加可取消导航请求。
4. 提供“保存并离开 / 不保存离开 / 继续编辑”对话框。
5. 为刷新与关闭标签页增加 `beforeunload` 提醒。

## 批次四：验证与交付

1. 运行 CAD、渲染任务及相关后端测试。
2. 运行前端生产构建。
3. 用真实 DXF 请求检查 JPG 像素、打印范围和标题栏内容。
4. 浏览器验证任务恢复和离开提醒。
5. 提交并自动推送至 `feat/semicircle-handles-and-quote-form-improvements`。
